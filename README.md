## About Me

Software engineer and tech lead focused on **scalable backends, cloud infrastructure, and useful AI-assisted engineering workflows**.

I like understanding the whole system: how data moves, where responsibilities belong, what breaks at scale, and whether the solution actually fits the product. I value clear architecture, pragmatic trade-offs, and shipping reliable software over adding complexity for its own sake.
